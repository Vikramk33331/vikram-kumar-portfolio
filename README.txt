VIKRAM KUMAR - PRACTICAL TRAINING PORTFOLIO

HOW TO PREVIEW
1. Extract this ZIP folder.
2. Open index.html in Chrome or Edge.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named vikram-kumar-portfolio.
3. Upload all files and folders from this website folder (not the ZIP itself).
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for GitHub Pages to publish and copy the public URL.

IMPORTANT
- The portfolio is a self-directed, ChatGPT-guided practical learning record, not an employer-issued or externally accredited internship certificate.
- Review every file and remove personal/sensitive information before making the repository public.
- Offer Letter is included as a sample training document; review it before publishing.
- QR code is not embedded yet because it must point to the final published URL.
